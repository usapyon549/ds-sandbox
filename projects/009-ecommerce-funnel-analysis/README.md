# 009-ecommerce-funnel-analysis

Polarsを用いた大規模ECデータのファネル分析。

15GB級のECサイト行動データを対象に、PolarsのLazyFrameを利用したデータ処理と、ユーザーサンプリングによる簡易的なファネル分析を行った。

## Summary

ECサイトの行動ログデータを用いて、`view → cart → purchase` のファネル分析を行った。

今回のデータセットは1億行を超える大規模データであるため、PolarsのLazyFrameを利用し、必要な列・必要なユーザーに絞りながら処理した。

また、全ユーザーをそのまま分析するのではなく、サンプリングによって分析対象を絞ることで、メモリ使用量を抑えながらファネル全体およびカテゴリ別の傾向を確認した。

## Dataset

Kaggleで公開されているECサイトの行動ログデータを使用。

- Dataset: [eCommerce behavior data from multi category store](https://www.kaggle.com/datasets/mkechinov/ecommerce-behavior-data-from-multi-category-store/data)
- 対象期間: 2019年10月、11月
- データ量: 約1.1億行
- ファイルサイズ: 約14GB
- ユニークユーザー数: 約531万

イベントは以下の3種類で構成されている。

- `view`
- `cart`
- `purchase`

## Analysis

### 1. Polars LazyFrameによる大規模データ処理

元データが非常に大きいため、`pl.scan_csv()` を利用してLazyFrameとして読み込んだ。

分析に必要な処理だけを実行することで、巨大なデータを一度にDataFrameへ読み込むことを避けた。

さらに、分析対象を必要な列・ユーザーに限定した。

```python
use_cols = ["user_id", "event_type"]

lazy_df_2019_oct.select(use_cols).filter(
    pl.col("user_id").is_in(target_user_ids)
)
```

このように、

- `select()` で必要な列だけを取得
- `filter()` で分析対象ユーザーだけを抽出
- LazyFrameのまま処理をつなげ、必要なタイミングで `collect()`

という形で、メモリ使用量を抑えながら分析を行った。

### 2. ファネル分析の定義

今回のファネル分析では、

> 各イベントを経験したユニークユーザー数を比較する

という簡易的な定義を採用した。

そのため、個々のユーザーについて、

`view → cart → purchase`

という順序でイベントが発生したかまでは追跡していない。

今回は「巨大な行動ログから、各イベントを経験したユーザーの規模を比較する」ことを目的とした。

### 3. サンプリング

元データには約531万のユニークユーザーが存在するため、まず1,000ユーザーをランダムに抽出し、ファネルの規模を確認した。

1,000ユーザーでの結果は以下となった。

| Event | Unique Users |
|---|---:|
| View | 1,000 |
| Cart | 200 |
| Purchase | 133 |

この結果から、`cart → purchase` の遷移を基準とすると、推定誤差が±6.5%となり、  
1,000ユーザーではサンプル数が少なく、推定誤差が大きいことが分かった。

そこで、1,000ユーザーで得られた `cart → purchase` の割合を基準として、概算で±2%程度の誤差を目標に必要なサンプル数を計算した。

その結果をもとに、分析対象を16,500ユーザーに設定した。

### 4. 全体のファネル

16,500ユーザーを対象に分析した結果は以下となった。

| Event | Unique Users |
|---|---:|
| View | 16,497 |
| Cart | 3,302 |
| Purchase | 2,148 |

離脱率は、

- `view → cart`: 約79.98%
- `cart → purchase`: 約34.94%

となった。

`view → cart` では大きくユーザーが減少しており、商品を閲覧したユーザーの多くがカート投入まで進んでいないことが分かった。

一方で、一度カートに入れたユーザーでは、購入まで進む割合が比較的高くなっている。

## Category Analysis

商品カテゴリごとにも、`view → cart → purchase` のファネルを確認した。

今回は `category_code` の先頭階層を利用し、以下のような大カテゴリにまとめた。

- `electronics`
- `appliances`
- `apparel`
- `computers`
- `accessories`
- `auto`
- `furniture`
- `construction`
- `sport`
- `kids`
- `medicine`
- `country_yard`
- `stationery`

カテゴリによってファネルの傾向には違いが見られた。

例えば、`electronics` では、

| 指標 | 結果 |
|---|---:|
| View | 9,529 |
| Cart | 1,965 |
| Purchase | 1,238 |
| View → Cart離脱率 | 約79.4% |
| Cart → Purchase離脱率 | 約37.0% |

となった。

一方、`accessories` では、

| 指標 | 結果 |
|---|---:|
| View | 359 |
| Cart | 8 |
| Purchase | 6 |
| View → Cart離脱率 | 約97.8% |
| Cart → Purchase離脱率 | 約25.0% |

となった。

このような違いから、カテゴリによってユーザーが離脱しやすい段階が異なる可能性がある。

例えば、`accessories` や `apparel` のように比較検討を行うユーザーが多いと仮定できるカテゴリでは、`view → cart` の離脱率が高い一方、`cart → purchase` の離脱率は比較的低い。

そのため、

- 商品説明の充実
- 商品の魅力を伝える情報の改善
- 比較検討時に参考となる情報の追加

など、カートに入れてもらうまでの施策が一案として考えられる。

一方、`electronics` のように目的の商品が比較的明確なユーザーが多いと仮定できるカテゴリでは、`view → cart` の離脱率は比較的低い。

そのため、

- 割引クーポン
- 購入時のキャンペーン
- カート投入後の購入促進施策

など、`cart → purchase` の遷移を高める施策が一案として考えられる。

ただし、これらは今回のファネル分析から考えられる施策案の一例であり、実際のユーザー属性や価格、商品内容などを考慮したものではない。

## Findings

今回の分析から、以下を確認した。

### 大規模データでは「全部読み込まない」ことが重要

15GB級のデータに対して、最初から全データをDataFrameとして扱うのではなく、

- LazyFrame
- 必要な列のみを `select()`
- 対象ユーザーのみを `filter()`
- 必要なタイミングで `collect()`

という処理を組み合わせることで、巨大なデータでも分析しやすくできることを確認した。

### サンプリングによって分析規模を現実的に調整できる

全ユーザーを対象とするのではなく、まず小規模なサンプルで傾向を確認し、その結果をもとに必要なサンプル数を概算した。

今回は1,000ユーザーで得られた `cart → purchase` の割合を基準に、概算で±2%程度の誤差を目標として16,500ユーザーを採用した。

### カテゴリによって離脱ポイントが異なる

全体のファネルだけではなくカテゴリ別に確認することで、

> 「どの段階でユーザーが離脱しているか」

という観点からカテゴリごとの違いを確認できた。

## Limitations

今回の分析にはいくつかの制約がある。

### ファネルの定義

今回は各イベントを経験したユニークユーザー数の比較としてファネルを定義した。

そのため、

```text
view
  ↓
cart
  ↓
purchase
```

というイベントの発生順序や、同一セッション内での行動までは考慮していない。

より厳密なファネル分析を行う場合は、`event_time` や `user_session` を利用して、ユーザーごとの行動順序を追跡する必要がある。

### カテゴリ別分析のサンプル数

カテゴリ別分析も、全体のファネル分析で使用した16,500ユーザーをそのまま利用している。

そのため、13カテゴリに分割したことでカテゴリによってサンプル数に大きな差が生じている。

特に、

- `medicine`
- `country_yard`
- `stationery`

などはサンプル数が少なく、購入イベントが存在しないカテゴリもあった。

したがって、カテゴリ別の離脱率については、サンプル数の不足による不確実性に注意する必要がある。

今回のカテゴリ別分析は、厳密な効果検証というよりも、大規模データからカテゴリごとの傾向を簡易的に把握するための探索的な分析として扱う。

## Future Work

今回は大規模データを扱うことと、簡易的なファネル分析を主な目的とした。

今後さらに分析する場合は、

- `user_session` を利用したセッション単位のファネル分析
- `event_time` を利用したイベント順序の追跡
- ユーザー属性ごとのファネル比較(本データセットに対応するデータセットがあるかは不明)
- 商品価格帯別のファネル比較(本データセットに対応するデータセットがあるかは不明)
- カテゴリ別のサンプル数を考慮した統計的検定
- サンプリングしていない、全ユーザーを対象とした分析との比較
- PolarsのLazyFrameを活用したより複雑な集計

などが考えられる。

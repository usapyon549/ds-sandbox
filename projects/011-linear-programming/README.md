# 011-linear-programming

線形計画問題（LP）と混合整数線形計画法（MILP）を用いた、工場の生産計画最適化。

## Summary

最適化問題を実際に実装してみることを目的として、**工場の生産量を最適化する問題**を題材に、LPとMILPを試した。

まずは、生産量・需要・生産能力といった基本的な制約を持つ問題をLPとして定式化し、  
その後、工場の稼働フラグや固定費を追加して、より現実的な生産計画をMILPとして定式化した。

今回は機械学習ではなく、「**条件の中で、利益を最大化するにはどうすればよいか**」  
という最適化問題そのものを理解することを目的としている。

## Dataset

工場・製品の条件は、最適化問題の学習用に作成した**自作のトイデータ**を使用している。

各条件には、後から単位を確認できるよう、

```text
数値_単位
```

の形式で単位を付与している。

最適化問題を作成する際には、数値部分を取り出して利用した。  
実際の業務データを再現することよりも、単位を明記することで最適化問題の構造をシンプルに確認できることを優先している。

## Optimization

### LP

まずは、東京・福岡の2工場を対象として、生産量を最適化した。

- 生産量：整数
- 需要制約
- 生産能力制約
- 利益最大化

目的関数は、各製品の販売価格と製造コストの差から利益を計算し、**工場全体の利益を最大化**するように設定した。

### Result

```text
Status: Optimal
tokyo_product_a = 0.0
tokyo_product_b = 80.0
fukuoka_product_a = 15.0
fukuoka_product_b = 100.0
Objective Value = 790.0
```

制約条件のもとで、最適な生産量が求められ、目的関数の値は **790** となった。

### MILP

次に、LPの問題に**工場を稼働させるかどうか**の判断を追加した。

- 生産量：整数
- 工場稼働：0/1
- 固定費
- 需要制約
- 生産能力 × 稼働フラグ
- 利益最大化

工場の稼働フラグを0/1の変数として追加し、工場を稼働させた場合のみ固定費が発生するようにした。

また、生産能力についても、

```text
生産能力 × 工場稼働フラグ
```

とすることで、稼働していない工場では生産できないという条件を表現した。

### Result

```text
Status: Optimal

tokyo_product_a = 0.0
tokyo_product_b = 80.0

fukuoka_product_a = 15.0
fukuoka_product_b = 100.0

osaka_product_a = 5.0
osaka_product_b = 100.0

tokyo_operation_flag: 1.0
fukuoka_operation_flag: 1.0
osaka_operation_flag: 1.0

Objective Value = 925.0
```

MILPでは大阪工場を含めた3工場が稼働する結果となり、固定費を考慮したうえでも生産することが利益最大化につながる結果となった。

目的関数の値は **925** となった。

### LPとMILPの比較

今回の実験では、LPからMILPへ条件を追加することで、より現実的な生産計画を表現できることを確認した。

|              | LP | MILP |
| ------------ | -- | ---- |
| 生産量          | 整数 | 整数   |
| 需要制約         | ○  | ○    |
| 生産能力制約       | ○  | ○    |
| 工場稼働フラグ      | -  | ○    |
| 固定費          | -  | ○    |
| 工場稼働と生産能力の連動 | -  | ○    |

LPでは「どれだけ生産するか」を中心に考えるのに対し、MILPでは「**そもそも工場を稼働させるか**」という意思決定まで含めて最適化できる。

## Notes
今回の実験では、最適化問題を単に解くだけでなく、**現実の意思決定を数式として表現すること**を体験できた。

特にMILPでは、

- 生産量を決める
- 工場を稼働させるか決める
- 稼働させた場合は固定費が発生する
- 稼働していない工場では生産できない

といった条件を、整数変数・0/1変数・制約として表現できる。

つまり、最適化では「モデルにデータを入れて予測する」のではなく、**目的・制約・意思決定変数を自分で定義し、その条件の中で最適な意思決定を探索する**という考え方が重要だと確認した。

なお、今回は学習目的のため、工場や製品の条件は自作のトイデータを使用している。
また、notebook上の「LP」では生産量を整数変数として設定しているため、厳密な数学上の分類では純粋な連続変数のみのLPではなく、**整数制約を含む線形最適化問題**として扱っている。

今回はLPとMILPの違いを段階的に確認することを優先した。

## Feature Work

今回は基本的な生産計画のみを扱ったが、さらに条件を追加することで、より複雑な最適化問題へ拡張できる。

例えば、

- 原材料の在庫制約
- 複数期間にわたる生産計画
- 輸送コスト
- 工場間の生産分担
- 製品ごとの優先度
- 残業や追加生産能力
- 複数の目的関数を考慮した最適化

などが考えられる。
